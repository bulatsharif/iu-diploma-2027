# Qwen3-8B: baseline без драфтера

Завершённая серия из 36 прогонов от 13 октября 2026 года, 12:28–15:08 МСК. Измеряет задержки и скорость исходной Qwen3-8B для последующего сравнения с драфтерами.

Деплой: 1 × NVIDIA H100 80 GB, GPU 2; `Qwen/Qwen3-8B`, BF16; vLLM 0.30.0, AIPerf 0.13.0. Thinking и prefix caching отключены, CUDA graphs включены. Генерация использует настройки модели: temperature 0.6, top_p 0.95, top_k 20. Полная сохранённая конфигурация, версии библиотек и хеши входных файлов находятся в [deployment.json](deployment.json).

Данные: по 100 историй WildChat на RU и EN, полный вход 70–130 токенов. Длина ответа около 100, 500 или 1000 токенов задаётся системной инструкцией; фактическая длина измеряется. Для каждого профиля выполнены `concurrency=1` и пуассоновские RPS 1/2/4/8/16: разминка 30 секунд, подача основной нагрузки 120 секунд, ожидание оставшихся ответов до 30 секунд.

## Файлы

- [tables.md](tables.md) — три итоговые таблицы, по 12 строк. Перцентили: p50 / p95 / p99; метрики принятия без драфтера обозначены `—`.
- [runs/](runs/) — 36 исходных сводных JSON-отчётов AIPerf, по одному на условие эксперимента.
- [request_counts.csv](request_counts.csv) — отправленные, завершённые, отменённые запросы и ошибки основной фазы; счётчики извлечены из лога AIPerf.
- [launch-fix.patch](launch-fix.patch) — применённое к исходному коммиту исправление запуска: флаг speculative-метрик допустим только с драфтером.

## Завершение запросов

Отправлено 22843, завершено 22459, отменено 384, ошибок 0. Все 36 прогонов завершились; код завершения серии — 0. Отмены произошли по истечении grace period. В `en_1000_rps_16` завершилось 1626 из 1972 запросов, остальные 346 отменены. Итоговые метрики отражают завершившиеся запросы; показатели при отменах не описывают все отправленные запросы.

## Повторение

Код эксперимента: `db899801ab688ea7c2183785430fa5430bb46a93` с применённым `launch-fix.patch`. При восстановлении этого коммита применить патч из этого каталога. Для повторения нужны локальная модель `models/Qwen3-8B`, подготовленные файлы `data/prompts` и окружение `.venv` с зависимостями из `requirements.txt`; подготовка описана в [процедуре экспериментов](../../docs/experiment-procedure.md).

Из корня проекта запустить baseline-сервер, затем во втором терминале — сетку:

```bash
CUDA_VISIBLE_DEVICES=2 bash scripts/serve_baseline.sh
.venv/bin/python scripts/run_benchmarks.py --output-dir results/baseline_repeat
```

Каталог `results/baseline_repeat` должен быть новым. После серии он содержит `tables.md` и отдельные каталоги с исходными отчётами. Архив сохраняет файлы из `results/baseline_20261013_092255`; модели, кэши и подробные записи запросов остаются в исходной рабочей директории.
